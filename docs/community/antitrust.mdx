This page applies to work in `HarshShinde0/geocr_mcp`. It covers meetings, issues, and pull requests that shape GeoCroissant tooling. It is not a copy of the upstream Model Context Protocol governance. Upstream MCP has its own antitrust guidance. This repo sets its own rules for Earth observation discovery and GeoCroissant generation.

## How this project works

- Decisions happen in public on GitHub at `https://github.com/HarshShinde0/geocr_mcp` in issues, pull requests, and discussions.
- Technical choices use open standards. For this repo that is STAC 1.0.0 via `pystac-client`, WGS84 bounding boxes, and MLCommons Croissant 1.1 with GeoCroissant 1.0 as implemented in `src/geocr_mcp_server/spec.py` and `src/geocr_mcp_server/eo.py`.
- Pricing, sales terms, and private contracts are out of scope. Do not discuss them in project channels.

## What to avoid

- Do not share non-public pricing or deal terms.
- Do not propose limits on who can run a STAC catalog or build a GeoCroissant dataset.
- Do not use project meetings to coordinate commercial activity.

Questions about this policy go in a GitHub issue. The maintainers respond there. This text is guidance for day to day work. It does not provide legal advice.
