You can build a client that calls `geocr-mcp-server` over stdio or streamable-http.

## Python stdio example

This example geocodes a place, counts scenes, and inspects a collection.

```python
import asyncio
import json
from mcp import ClientSession, StdioServerParameters
from mcp.client.stdio import stdio_client

async def main():
    server_params = StdioServerParameters(
        command="uvx",
        args=["geocr-mcp-server"]
    )

    async with stdio_client(server_params) as (read, write):
        async with ClientSession(read, write) as session:
            await session.initialize()

            # 1. Place to bbox
            geo = await session.call_tool(
                "geocode_place",
                arguments={"place_name": "San Francisco, CA", "limit": 5}
            )
            data = json.loads(geo.content[0].text)
            bbox = data["candidates"][0]["bbox"]  # [min_lon, min_lat, max_lon, max_lat]

            # 2. List collections
            cols = await session.call_tool(
                "search_eo_datasets",
                arguments={"catalog_id": "earth-search", "limit": 15, "offset": 0}
            )
            print(cols.content[0].text)

            # 3. Count scenes before fetching
            counted = await session.call_tool(
                "count_eo_scenes",
                arguments={
                    "bbox": bbox,
                    "collections": ["sentinel-2-c1-l2a"],
                    "catalog_id": "earth-search",
                    "datetime_range": "2024-06-01/2024-06-30",
                    "max_cloud_cover": 20
                }
            )
            print(counted.content[0].text)

if __name__ == "__main__":
    asyncio.run(main())
```

Notes on parameters:

- `bbox` is required for `count_eo_scenes` and `search_eo_scenes` and must be `[min_lon, min_lat, max_lon, max_lat]` EPSG:4326.
- `collections` is a list of explicit collection ids. Use `search_eo_datasets` to find them first.
- `limit` for `search_eo_scenes` is 1 to 50, default 10. For `geocode_place` it is 1 to 10, default 5.

## Handling GeoCroissant output

Generation tools return `json_ld`, `asset_urls`, `asset_count`, and a validation report. Write the document to disk only when `output_filename` is set; the server writes under `GEOCR_OUTPUT_DIR` or the system temp directory.
