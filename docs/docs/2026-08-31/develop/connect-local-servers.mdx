Run `geocr-mcp-server` as a local subprocess over stdio. Python 3.10 or newer is required.

## Prerequisites

- Python 3.10 or higher.
- `uv` or `pip`.

```bash
curl -LsSf https://astral.sh/uv/install.sh | sh
```

## Installation

No checkout is needed for normal use:

```bash
uvx --from "geocr-mcp @ git+https://github.com/HarshShinde0/geocr_mcp.git@main" geocr-mcp-server
```

To install into the active environment:

```bash
pip install git+https://github.com/HarshShinde0/geocr_mcp.git@main
```

Docker also works (see connect remote servers):

```bash
docker build -t geocr-mcp-server .
docker run -i --rm geocr-mcp-server
```

## Client configuration

All seven clients below use different filenames and remote-server keys. Use the example for your client rather than copying between clients. Hosted endpoint for every client is `https://geocr-mcp-server.onrender.com/mcp`.

## Environment variables

| Variable | Default | Purpose |
| --- | --- | --- |
| `FASTMCP_LOG_LEVEL` | `WARNING` | Set stderr logging to `DEBUG`, `INFO`, `WARNING`, or `ERROR`. |
| `GEOCR_OUTPUT_DIR` | System temp directory | Where `output_filename` is written; names are reduced to basename. |
| `GEOCR_CATALOGS_CONFIG` | Bundled `src/geocr_mcp_server/config/catalogs.yaml` | Load catalog definitions from another YAML file. |
| `GEOCR_HOST` | `127.0.0.1` locally; `0.0.0.0` in cloud | Bind address for HTTP. |
| `GEOCR_PORT` | `8000` | Port for HTTP. |
| `GEOCR_TRANSPORT` | `stdio` locally; `streamable-http` in cloud | Select the MCP transport. |

## Verifying

Call `ping` and expect `pong`. Then call `list_eo_catalogs` and check for `earth-search` at `https://earth-search.aws.element84.com/v1` and `veda` at `https://openveda.cloud/api/stac`. For network and file handling, note that all STAC, geocoding, and preview calls hit live services, and generated files are written inside `GEOCR_OUTPUT_DIR` with basename only.
