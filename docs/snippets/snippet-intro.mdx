GeoCroissant snippets are reusable blocks for dataset metadata.

Use a snippet when the same description, license, or responsible AI statement appears in more than one document. Edit the snippet once and each document that includes it stays consistent. This avoids drift between copies of the same text.

Snippets in this section use GeoCroissant fields only. They do not include generic Croissant examples that lack spatial coverage, CRS, or band metadata. If a block does not contain `geocr:` properties or `conformsTo` with `http://mlcommons.org/croissant/geo/1.0`, it does not belong here.
