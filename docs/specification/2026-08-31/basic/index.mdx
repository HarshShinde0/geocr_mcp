`geocr-mcp-server` implements the MCP base protocol with JSON-RPC 2.0 and per-request metadata in `_meta`. The protocol version for this release is `2026-08-31`.

## Characteristics

- Message format is JSON-RPC 2.0 with `jsonrpc: "2.0"`.
- Transports are `stdio` and `streamable-http` at `/mcp` (`https://geocr-mcp-server.onrender.com/mcp` when hosted). The server does not expose the legacy `GET /sse` endpoint.
- Every request carries `io.modelcontextprotocol/protocolVersion` and client info in `_meta`. Over streamable HTTP the same version is mirrored in the `MCP-Protocol-Version` header and the two values must match.
