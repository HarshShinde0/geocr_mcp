`geocr-mcp-server` implements server features as tools only. It does not expose resources or prompts. Client features such as roots, sampling and elicitation are documented under [Client](/specification/2026-08-31/client/roots) as protocol reference, but this server does not call them.

All tool results are validated with `mlcroissant` where a document is produced. The server keeps provider-native `contentUrl` values and does not claim that multi-source RecordSets are aligned.
